# Mask “Retro”

The look of several boot stages, put together and exported with [Ekpo](https://github.com/nomoruyi/ekpo):

- `boot-splash/Dots`: the boot splash (Plymouth theme), the imported theme “Dots” by its own author, as imported; install it as its author describes.
- `plasma-splash/ekpo-dawn-v1`: the Plasma splash (look-and-feel package); its README.md says how to install it.
