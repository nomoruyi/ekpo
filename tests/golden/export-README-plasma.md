# Dawn

A Plasma splash (look-and-feel package) made with [Ekpo](https://github.com/nomoruyi/ekpo), from version 1 of the design.

By nomoruyi, under the MIT licence (LICENSE).

- The image “Logo”: licence unknown

## Install

In System Settings: Colours & Themes → Splash Screen → Install from File, and choose this archive; then pick “Dawn” there. Or:

```sh
kpackagetool6 -t Plasma/LookAndFeel -i ekpo-dawn-v1.tar.gz
```
